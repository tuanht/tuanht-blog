This blog now runs on [Astro](https://astro.build). The look comes from *Tuamatic*,
my old child theme of Thematic.

## Why move

- Static output, no PHP or database.
- Markdown content in git.
- Fast pages with almost no JavaScript.

### Build it

```bash
npm install
npm run build
```

> Simplicity is prerequisite for reliability.

| Before    | After  |
| --------- | ------ |
| WordPress | Astro  |
| MySQL     | Files  |
